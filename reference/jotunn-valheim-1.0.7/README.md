Names of every character (with its components), item and prefab in Valheim 1.0.7, extracted from the
lists Jötunn generates from the game with its JotunnDoc mod (Valheim-Modding/Jotunn,
JotunnLib/Documentation/data, MIT). Used by tests/Data/check_data.py to check the base prefabs Scotheim
clones and the items it names. Not loaded by the mod.
